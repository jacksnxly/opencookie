## A small runtime with hard boundaries

<CardGrid>
  <Card title="Denied until allowed" icon="lock">
    Scripts and frames start inert. The effective decision activates declared
    resources, not a hopeful timing convention.
  </Card>
  <Card title="One domain model" icon="seti">
    React, Vue, Svelte, Next, Nuxt, Astro, and plain HTML bind to the same typed
    core instead of copying consent rules.
  </Card>
  <Card title="A decision you can audit" icon="document">
    Policy identity, transition events, persistence diagnostics, and optional
    receipts are explicit outputs.
  </Card>
</CardGrid>

OpenCookie construction is SSR-safe. Browser storage is read only when the host calls `initialize()`.

## Choose a route

- Run a site: [create a site, publish a policy, and check that rejection worked](/operating/run-a-site/)
- First installation: [initialize a supported application](/getting-started/)
- No build step: [plain HTML self-hosting or a pinned CDN build](/getting-started/plain-html/)
- Client applications: [React](/getting-started/react-vite/), [Vue](/getting-started/vue-vite/), or [SvelteKit](/getting-started/sveltekit/)
