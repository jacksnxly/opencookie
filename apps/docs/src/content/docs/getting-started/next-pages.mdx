## Verified fresh-app workflow

Create an empty directory, enter it, then run these exact commands in order. Keep the import alias quoted so the shell does not expand `*` before the scaffold receives it.

- Scaffold: `pnpm dlx create-next-app@16.3.2 . --ts --no-linter --no-tailwind --no-app --empty --no-src-dir --no-react-compiler --import-alias '@/*' --no-agents-md --disable-git --skip-install --yes`
- Install: `pnpm install --no-frozen-lockfile`
- Initialize: `npx --yes opencookie@0.4.1 init --yes`
- Build: `pnpm build`
- Serve: `pnpm start --hostname 127.0.0.1 --port 4173`

Open `http://127.0.0.1:4173/` to inspect the production build and its initialized banner.

Observed output: Next compiled successfully, prerendered the root route, the production build exited 0, and the production server returned HTTP 200.

## Browser-verified result

This exact production workflow was exercised from a clean storage state in a real browser. Before consent, `opencookie-demo.js` had zero requests and zero executions. Accept all persisted across a new navigation. Analytics was then denied with Save choices, consent was withdrawn, and a final navigation again produced zero demo requests and executions.
